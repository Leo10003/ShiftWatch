# ShiftWatch 0.9.0

This release establishes the standardized ShiftWatch versioning scheme.

## Versioning policy

ShiftWatch now uses Semantic Versioning for the user-visible version:

- PATCH: bug fixes and narrowly scoped corrections
- MINOR: backwards-compatible features and workflow improvements
- MAJOR: stable compatibility or product-boundary changes

Android versionCode remains monotonically increasing and is independent
from the user-visible semantic version.

## Baseline

0.9.0 incorporates the recognition, anchored review, same-block
corroboration, OCR-backed review stability, and ambiguous-time review work
developed through the former 20.8.x development series.
