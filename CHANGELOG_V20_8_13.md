- Diagnostic scope now scores the strongest two distinct candidates **inside physical block 2 across all seven weekday columns** using the same original/widen/trim options; previously only Thursday, Friday, and Saturday were tested. These are **investigative hypotheses derived from one reference photograph**, not calibrated production thresholds.
